# v1.2.0

这是网络ASR的第一个公开版本。我把原来的转写流程整理成了一个 Windows 桌面工具，界面保留文件选择、抖音导入、转写记录和设置。

- 支持本地音视频和抖音分享文案。
- 接入火山引擎大模型录音文件识别极速版，使用自己的 API Key。
- 支持后台队列、失败重试、文字稿复制与 TXT 导出。
- 配置和历史保存在本机，密钥使用 Windows DPAPI 加密。
- Windows 10/11 x64 便携包内含 Python、Qt WebEngine、FFmpeg 和下载浏览器，不需要另装运行环境。

下载 `NetworkASR-v1.2.0-windows-x64.zip`，完整解压到普通文件夹，再双击 `网络ASR.exe`。不要在压缩包里直接运行，也不要只复制 exe。

转写和抖音下载需要联网。软件不包含 ASR 免费额度；费用由火山引擎收取。具体设置、价格参考和使用限制见仓库 README。
